1Clip

Press Alt Shift S on a site and write one line about what caught your eye. While you're away, Artspo scrolls the page and records its palette, type, shapes and every animation.

2Distill

Your agent finds what your clips share: languages (whole looks) and techniques (single moves), each with a recipe, a live specimen and the evidence behind it.

3Make

Ask for a brand direction, a motion spec or a page. Each work lists the patterns and clips it came from, and the catalogue lets you trace any of it back.

Start your book.

Chrome 118 or newer. Python 3 is optional; agents use it to build the catalogue.

Share your book today
python3 extension/skills/artspo/catalogue.py ~/Downloads/artspo --public --site ~/artbook-site

1Get the code and the skill

git clone https://github.com/bryfeng/artspo ~/code/artspo
cd ~/code/artspo && sh install.sh

2Load the extension

Open chrome://extensions, turn on Developer mode, click Load unpacked and choose the extension folder. Pin Artspo to the toolbar.

3Clip something

Pick where clips go, name a few collections, then press Alt Shift S on a site you like.
